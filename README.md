# KTX 빈자리 모니터 — 4단계

## 이번 단계에서 바뀐 기능

- 국토교통부 TAGO 공식 역 목록 사용
- 실제 열차번호와 출도착 시간표 조회
- KTX 계열 열차 필터
- 사용자별 Telegram 연결코드
- 사용자의 열차 선택과 Chat ID를 Session State로 분리
- 공식 역 목록 24시간 공유 캐시
- 동일 시간표 요청 60초 공유 캐시
- 사용자별 빠른 반복 조회 제한

좌석 재고는 TAGO API가 제공하지 않으므로 아직 연습용 시뮬레이션입니다.

---

# 1. 공공데이터 API 활용신청

공공데이터포털에서 다음 API를 검색합니다.

```text
국토교통부_(TAGO)_열차정보
```

`활용신청`을 누르고 개발계정을 신청합니다.

신청 목적 예시:

```text
KTX 운행 시간표 조회 및 빈자리 알림 웹앱 개발 테스트
```

승인 후 마이페이지에서 일반 인증키를 확인합니다.

가능하면 다음 키를 복사합니다.

```text
일반 인증키(Decoding)
```

# 3. Streamlit Secrets 수정

배포된 앱에서 다음으로 이동합니다.

```text
Manage app
→ Settings
→ Secrets
```

다음 두 값만 있으면 됩니다.

```toml
DATA_GO_KR_SERVICE_KEY = "공공데이터포털 일반 인증키(Decoding)"
TELEGRAM_BOT_TOKEN = "BotFather가 발급한 기존 토큰"
```

이전 단계의 아래 두 값은 이번 코드에서 사용하지 않습니다.

```toml
TELEGRAM_CHAT_ID = "..."
SETUP_PIN = "..."
```

남겨두어도 오류는 없지만 삭제해도 됩니다.

# 4. 배포 후 테스트

## Telegram 사용자별 연결

1. `텔레그램에서 내 알림 연결하기`를 누릅니다.
2. Telegram에서 봇의 `시작`을 누릅니다.
3. 앱으로 돌아옵니다.
4. `텔레그램 연결 확인`을 누릅니다.
5. 연결된 이름이 표시되는지 확인합니다.
6. `테스트 메시지 보내기`를 누릅니다.

## 공식 시간표 조회

1. 출발역 `청량리`
2. 도착역 `동해`
3. 원하는 날짜
4. `공식 열차 시간표 조회`
5. 실제 열차번호와 출도착 시간이 표시되는지 확인합니다.

해당 날짜 또는 시간대에 KTX가 없다면:

- `KTX 계열만 표시`를 해제합니다.
- 시간 조건을 앞당깁니다.
- 다른 날짜로 조회합니다.

## 연습용 좌석 알림

1. 공식 시간표에서 열차 한 개를 선택합니다.
2. 조회 간격 `5초`
3. 발견 시점 `3번째 조회`
4. 모니터링을 시작합니다.
5. 연결한 사용자 본인의 Telegram으로 알림이 오는지 확인합니다.

# 여러 사용자 배포 관점의 현재 제한

Streamlit Session State는 사용자 세션별로 분리되지만 새로고침하면 초기화됩니다.

따라서 현재 버전에서는 각 사용자가 페이지를 새로고침할 때 Telegram 연결을 다시 해야 합니다.

다음 단계에서는 Supabase를 연결해서 아래 정보를 사용자 계정별로 저장합니다.

```text
사용자 계정
Telegram Chat ID
저장된 여행 조건
모니터링 작업
알림 전송 이력
```

공개 서비스에서 브라우저를 닫아도 작동하려면 Streamlit 외에 별도의
백그라운드 Worker 서버가 필요합니다.
